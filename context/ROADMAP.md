\# Roadmap



\## V1 — MVP



Goal:



A creator can build and publish a TFT guide with optional board steps.



Features:



\- Auth

\- Guide CRUD

\- Board step CRUD

\- Board builder

\- Champion/item data

\- Public guide page

\- Planner code copy



\## V1.1 — Quality Improvements



Features:



\- Better board visuals

\- Better mobile public guide

\- Champion filters

\- Item filters

\- Guide preview

\- Duplicate guide

\- Better slug handling

\- SEO metadata

\- Public guide image preview



\## V1.2 — Creator Tools



Features:



\- Export board image

\- Import from planner code

\- Guide templates

\- Version guide by patch

\- Add alternative boards

\- Add "when to play" section

\- Add "augment priority" section

\- Add "item priority" section



\## V2 — Community



Features:



\- Public guide discovery

\- Likes/upvotes

\- Comments

\- Creator profiles

\- Follow creators

\- Featured guides

\- Meta categories



\## V3 — Data/AI



Features:



\- Riot API integration

\- Match history import

\- AI suggestions

\- Compare user board to guide board

\- Suggest transitions

\- Suggest item holders

\- Suggest roll/level timings
